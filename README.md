# جيبي · Jeybi

تطبيق شخصي لإدارة المال، مصمم لنواكشوط: كم لديك، أين صرفته، ومن أين يأتي دخلك — مع تقارير يومية وأسبوعية وشهرية وسنوية.

- يعمل **بالكامل بدون إنترنت** بعد أول فتح، ويُثبَّت على الشاشة الرئيسية للهاتف (PWA).
- **كل البيانات على جهازك فقط** (IndexedDB): لا سيرفر، لا حسابات، لا إرسال لأي بيانات.
- العربية والفرنسية، أرقام لاتينية دائمًا، والعملة الافتراضية الأوقية (MRU).

## المزايا

- **المحافظ:** نقد، بنكيلي، مصرفي، السداد، حساب بنكي (+ محافظ خاصة بك)، مع التحويل بينها ورسوم التحويل.
- **إدخال سريع:** زر `+` ← المبلغ ← التصنيف = عملية محفوظة. قوالب بلمسة واحدة (مثل "تاكسي 100").
- **تفاصيل اختيارية:** ملاحظة، تاريخ ووقت، صورة الوصل (تصوير أو من المعرض)، وسوم (`#عرس`، `#سفر_روصو`)، وتقسيم عملية على عدة تصنيفات.
- **تراجع** بعد الحذف أو التعديل، **محذوفات** قابلة للاسترجاع، و**سجل تغييرات** لكل عملية.
- **بحث وفلاتر** مع مجموع النتائج (مثال: كم صرفت على النقل في رمضان؟).
- **تقارير:** دخل، مصروف، صافي، أرصدة البداية والنهاية، مقارنة بالفترة السابقة، توزيع حسب التصنيف والمصدر والمحفظة، رسم زمني، أكبر 10 مصاريف، وصفحة **"أين ذهب مالي؟"**.
- **تصدير:** Excel، PDF (العربية تظهر متصلة وصحيحة)، وصورة للمشاركة على واتساب.
- **أمان:** قفل برمز PIN (مُجزّأ بـ PBKDF2) وفتح بالبصمة (WebAuthn، محلي بالكامل).
- **نسخ احتياطي:** ملف واحد (مع صور الوصولات) يُجهَّز ثم يُشارَك بزر "مشاركة الآن" (يظهر بامتداد txt على Android) أو يُنزَّل، واستيراد مع معاينة، وتذكير أسبوعي. النسخ القديمة (المرحلة الأولى) تبقى قابلة للاستيراد.
- **سجل الأخطاء:** الإعدادات ← سجل الأخطاء: آخر 50 خطأ (بلا أي مبالغ) للنسخ أو المشاركة مع المطوّر.

### المرحلة الثانية

- **الديون والسلف:** "لي عند فلان" و"علي لفلان"، سداد جزئي متعدد مع المتبقي، إغلاق تلقائي، والديون المتأخرة بلون مميز. تُحرّك المحافظ ولا تُحسب دخلًا ولا مصروفًا.
- **الميزانيات:** حد شهري لكل تصنيف، شريط تقدم، تنبيه عند 80% و100%، وتكرار ميزانيات الشهر الماضي بلمسة.
- **العمليات المتكررة:** يوميًا/أسبوعيًا/شهريًا/سنويًا، تسجيل تلقائي أو بانتظار التأكيد. تُنشأ عند فتح التطبيق كل العمليات المستحقة منذ آخر فتح، مرة واحدة فقط.
- **أهداف الادخار:** مبلغ وتاريخ مستهدف وصورة، ادّخار وسحب، والمبلغ المطلوب شهريًا. المبالغ المخصصة تبقى في محافظها وتظهر "مخصصة".
- **مطابقة الرصيد:** إدخال الرصيد الحقيقي لكل محفظة، عرض الفرق، وتسجيله كمصروف/دخل غير مسجَّل، مع تذكير كل أسبوعين.
- **التذكير اليومي:** بانر إن لم تُسجَّل أي عملية اليوم بعد ساعة تختارها (افتراضيًا 8 مساءً)، وإشعار تجريبي.
- **مؤشرات ذكية:** متوسط الصرف اليومي، الرصيد المتوقع آخر الشهر، وملاحظات عند الفروق الواضحة (3 كحد أقصى، بعتبة قابلة للضبط).
- **العملات المتعددة:** تسجيل عملية باليورو أو الدولار أو عملة تضيفها، بسعر صرف يدوي؛ كل الأرصدة والتقارير بالأوقية.
- **الزكاة:** نصاب الذهب أو الفضة بسعر غرام يدوي، اختيار المحافظ والديون، الحول بالتاريخ الهجري (أم القرى)، الحساب خطوة بخطوة، وتسجيل الإخراج. للاسترشاد فقط.

## التشغيل محليًا

المتطلبات: [Node.js](https://nodejs.org) الإصدار 20 أو أحدث (جُرّب على 24).

```bash
npm install
```

```bash
npm run dev
```

ثم افتح `http://localhost:5173`. لتجربته على هاتفك في نفس شبكة Wi-Fi:

```bash
npm run dev -- --host
```

وافتح العنوان الذي يظهر (`http://192.168.x.x:5173`). ملاحظة: البصمة والتثبيت كتطبيق يحتاجان HTTPS، لذا جرّبهما على النسخة المنشورة.

أوامر أخرى:

| الأمر | الوظيفة |
|---|---|
| `npm test` | تشغيل الاختبارات (الأرصدة، التحويلات، التقسيم، الفترات، التراجع، النسخ الاحتياطي، البحث، الديون، التكرار، العملات، الزكاة، الترحيل…) |
| `npm run build` | فحص الأنواع وبناء النسخة النهائية في `dist/` |
| `npm run preview` | تجربة النسخة النهائية محليًا (مع Service Worker) |
| `npm run icons` | إعادة توليد أيقونات التطبيق |

## التحديثات

عند نشر نسخة جديدة، تُنزَّل في الخلفية عند فتح التطبيق وتنتظر: **تُطبَّق عند إغلاق التطبيق وإعادة فتحه** (أو فورًا من بانر "نسخة جديدة جاهزة"). لا تُعاد الصفحة أثناء الاستعمال، ولا حاجة لحذف التطبيق. تغييرات قاعدة البيانات تتم بترحيل يحافظ على كل البيانات (`src/data/db.ts`، ومختبَر في `src/tests/migration.test.ts` على قاعدة حقيقية من المرحلة الأولى).

## النشر المجاني على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub (مثلًا باسم `jeybi`).
2. ارفع المشروع:
   ```bash
   git remote add origin https://github.com/<اسمك>/jeybi.git
   ```
   ```bash
   git push -u origin main
   ```
3. في المستودع: **Settings ← Pages ← Source** واختر **GitHub Actions**.
4. كل `push` إلى `main` يشغّل الاختبارات ثم يبني وينشر تلقائيًا (الملف `.github/workflows/deploy.yml`). يضبط المسار `BASE_PATH` باسم المستودع تلقائيًا.
5. الرابط يكون: `https://<اسمك>.github.io/jeybi/`

### بديل: Netlify

اربط المستودع بـ Netlify، والإعدادات جاهزة في `netlify.toml` (الأمر `npm run build`، المجلد `dist`).

## تثبيت التطبيق على هاتف Android

1. افتح رابط التطبيق في **Chrome** على الهاتف.
2. انتظر حتى يكتمل التحميل (مرة واحدة فقط — بعدها يعمل بدون إنترنت).
3. اضغط على قائمة **⋮** أعلى المتصفح ← **إضافة إلى الشاشة الرئيسية** / **تثبيت التطبيق**.
4. ستظهر أيقونة **جيبي** على الشاشة الرئيسية، ويفتح كتطبيق مستقل بدون شريط المتصفح.

نصائح مهمة:
- البيانات محفوظة في هذا المتصفح على هذا الهاتف فقط. **لا تمسح بيانات Chrome** للموقع، واحفظ **نسخة احتياطية** بانتظام (الإعدادات ← النسخ الاحتياطي) وأرسلها لنفسك على واتساب.
- لتفعيل البصمة: الإعدادات ← القفل والبصمة ← أنشئ رمز PIN ثم فعّل البصمة.
- عند نشر تحديث جديد، يتحدّث التطبيق تلقائيًا عند فتحه التالي مع اتصال بالإنترنت.

## البنية التقنية

React + TypeScript + Vite، و Tailwind CSS v4 (مع RTL)، و Dexie (IndexedDB)، و `vite-plugin-pwa`، و `react-i18next`، و Recharts، و SheetJS، و `html-to-image` + `jsPDF`.

```
src/
  data/       نموذج البيانات وقاعدة Dexie والقيم الافتراضية
  repo/       كل الوصول للبيانات (المحافظ، التصنيفات، العمليات، القوالب، الديون، الميزانيات، المتكررة، الأهداف، الزكاة، النسخ الاحتياطي…)
  services/   حسابات صافية (التقارير، الأرصدة، الفلترة) + الأمان + التصدير
  lib/        المال (×100) والتنسيق والفترات
  hooks/      ربط React بالبيانات والإعدادات
  components/ مكونات الواجهة (نافذة الإدخال، القفل، الرسوم…)
  pages/      الشاشات
  i18n/       العربية والفرنسية
  tests/      الاختبارات
```

- المبالغ مخزّنة كأعداد صحيحة (×100) لتجنّب أخطاء الكسور.
- الواجهة لا تصل لقاعدة البيانات إلا عبر `src/repo/` — ما يسهّل التحويل لاحقًا إلى تطبيق Android عبر Capacitor.
- مخطط قاعدة البيانات مرقّم: `version(1)` للمرحلة الأولى و`version(2)` للثانية (جداول جديدة فقط، دون تعديل البيانات القائمة). أي تغيير لاحق = `version(3)`.
