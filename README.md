# جيبي · Jeybi

تطبيق شخصي لإدارة المال، مصمم لنواكشوط: كم لديك، أين صرفته، ومن أين يأتي دخلك — مع تقارير يومية وأسبوعية وشهرية وسنوية.

- يعمل **بالكامل بدون إنترنت** بعد أول فتح، ويُثبَّت على الشاشة الرئيسية للهاتف (PWA).
- **كل البيانات على جهازك فقط** (IndexedDB): لا سيرفر، لا حسابات، لا إرسال لأي بيانات.
- العربية والفرنسية، أرقام لاتينية دائمًا، والعملة الافتراضية الأوقية (MRU).

## المزايا

- **المحافظ:** نقد، بنكيلي، مصرفي، السداد، حساب بنكي (+ محافظ خاصة بك)، مع التحويل بينها ورسوم التحويل.
- **إدخال سريع:** زر `+` ← المبلغ ← التصنيف = عملية محفوظة. قوالب بلمسة واحدة (مثل "تاكسي 100").
- **تفاصيل اختيارية:** ملاحظة، تاريخ ووقت، صورة الوصل (تصوير أو من المعرض)، وسوم (`#عرس`، `#سفر_روصو`)، وتقسيم عملية على عدة تصنيفات.
- **تراجع** بعد الحذف أو التعديل، **محذوفات** قابلة للاسترجاع، و**سجل تغييرات** لكل عملية.
- **بحث وفلاتر** مع مجموع النتائج (مثال: كم صرفت على النقل في رمضان؟).
- **تقارير:** دخل، مصروف، صافي، أرصدة البداية والنهاية، مقارنة بالفترة السابقة، توزيع حسب التصنيف والمصدر والمحفظة، رسم زمني، أكبر 10 مصاريف، وصفحة **"أين ذهب مالي؟"**.
- **تصدير:** Excel، PDF (العربية تظهر متصلة وصحيحة)، وصورة للمشاركة على واتساب.
- **أمان:** قفل برمز PIN (مُجزّأ بـ PBKDF2) وفتح بالبصمة (WebAuthn، محلي بالكامل).
- **نسخ احتياطي:** ملف واحد (مع صور الوصولات) يُجهَّز ثم يُشارَك بزر "مشاركة الآن" (يظهر بامتداد txt على Android) أو يُنزَّل، واستيراد مع معاينة، وتذكير أسبوعي. النسخ القديمة (المرحلة الأولى) تبقى قابلة للاستيراد.
- **سجل الأخطاء:** الإعدادات ← سجل الأخطاء: آخر 50 خطأ (بلا أي مبالغ) للنسخ أو المشاركة مع المطوّر.

### المرحلة الثانية

- **الديون والسلف:** "لي عند فلان" و"علي لفلان"، سداد جزئي متعدد مع المتبقي، إغلاق تلقائي، والديون المتأخرة بلون مميز. تُحرّك المحافظ ولا تُحسب دخلًا ولا مصروفًا.
- **الميزانيات:** حد شهري لكل تصنيف، شريط تقدم، تنبيه عند 80% و100%، وتكرار ميزانيات الشهر الماضي بلمسة.
- **العمليات المتكررة:** يوميًا/أسبوعيًا/شهريًا/سنويًا، تسجيل تلقائي أو بانتظار التأكيد. تُنشأ عند فتح التطبيق كل العمليات المستحقة منذ آخر فتح، مرة واحدة فقط.
- **أهداف الادخار:** مبلغ وتاريخ مستهدف وصورة، ادّخار وسحب، والمبلغ المطلوب شهريًا. المبالغ المخصصة تبقى في محافظها وتظهر "مخصصة".
- **مطابقة الرصيد:** إدخال الرصيد الحقيقي لكل محفظة، عرض الفرق، وتسجيله كمصروف/دخل غير مسجَّل، مع تذكير كل أسبوعين.
- **التذكير اليومي:** بانر إن لم تُسجَّل أي عملية اليوم بعد ساعة تختارها (افتراضيًا 8 مساءً)، وإشعار تجريبي.
- **مؤشرات ذكية:** متوسط الصرف اليومي، الرصيد المتوقع آخر الشهر، وملاحظات عند الفروق الواضحة (3 كحد أقصى، بعتبة قابلة للضبط).
- **العملات المتعددة:** تسجيل عملية باليورو أو الدولار أو عملة تضيفها، بسعر صرف يدوي؛ كل الأرصدة والتقارير بالأوقية.
- **الزكاة:** نصاب الذهب أو الفضة بسعر غرام يدوي، اختيار المحافظ والديون، الحول بالتاريخ الهجري (أم القرى)، الحساب خطوة بخطوة، وتسجيل الإخراج. للاسترشاد فقط.

### اكتب يومك (الإدخال الذكي)

زر **«اكتب يومك»** بجانب `+` في الرئيسية: اكتب يومك في جملة واحدة كرسالة واتساب، مثل:
`خبز 50، تاكسي 100، رصيد 200 من بنكيلي، ودخلتني عمولة 2000`
فتظهر فورًا بطاقة لكل عملية (النوع، المبلغ، التصنيف، المحفظة، التاريخ، والجزء الذي فُهمت منه). راجعها، المس أي بطاقة لتعديلها أو احذفها، ثم **حفظ الكل** (مع زر تراجع). **لا يُحفظ شيء قبل ذلك.**

- يفهم: الأرقام اللاتينية والمشرقية وفواصل الآلاف (`5,000` `5 000` `٥٠٠٠`)، والأرقام بالكلمات (مية، ميتين، ألف وخمسمية، 3 آلاف، مليون ونص، deux mille)، و«أوقية قديمة» (÷10)، واليورو والدولار بآخر سعر صرف محفوظ.
- النوع: دخل (دخلتني، وصلني، جاني، استلمت، راتب، عمولة، reçu، salaire…)، تحويل (حولت 1000 من بنكيلي للكاش)، دين (سلفت أحمد 500، تسلفت من سيدي 2000)، والباقي مصروف.
- التصنيف من قاموس محلي بالعربية والحسانية والفرنسية (خبز، أتاي، حوت، ليصانص، الضو، كراء، دراعة، pain، essence…) ومن أسماء تصنيفاتك. المحفظة من «من بنكيلي، بالسداد، كاش…» وإلا آخر محفظة مستعملة. التاريخ: اليوم، أمس/البارح/hier، أول أمس، أو يوم من الأسبوع.
- **يتعلّم:** إن صحّحت تصنيف كلمة أو محفظتها («عشاء ← عائلة») يتذكّرها. عرضها وتعديلها وحذفها من **الإعدادات ← الكلمات المتعلَّمة**، وهي تدخل في النسخة الاحتياطية.
- ما لم يُفهم يظهر بلون مميز مع زر «إضافة كعملية». الجملة كاملة تُحفظ مع كل عملية، فيجدها البحث.
- **بالصوت:** زر الميكروفون (في تطبيق Android: التعرّف على الكلام في الهاتف؛ في المتصفح: إن كان يدعمه). النص يوضع في الخانة لتصححه قبل التحليل.
- **من واتساب (Android):** «مشاركة» ← جيبي على أي رسالة، فتفتح هذه الشاشة والنص فيها (بعد القفل إن كان مفعّلًا).
- كل شيء على الجهاز: قواعد + قاموس، بدون إنترنت ولا ذكاء اصطناعي خارجي. يُحمَّل عند فتح هذه الشاشة فقط.

### تحسينات الاستعمال اليومي

- **المحفظة إلزامية:** لا محفظة مختارة مسبقًا في أي عملية جديدة (مصروف، دخل، تحويل، دين وسداده، الادخار، المتكررة، الزكاة). المحافظ أزرار كبيرة مع رصيد كل منها. القوالب والمتكررة تحفظ محفظتها؛ القالب القديم بلا محفظة يطلبها مرة واحدة.
- **الرصيد السالب: تحذير لا منع.** قبل أي عملية تنزل بمحفظة تحت الصفر: الرصيد الآن وبعدها و«هل نسيت تسجيل دخل؟» مع متابعة/تعديل. المحفظة السالبة حمراء مع زر «مطابقة الرصيد». في إعدادات المحفظة: «السماح بالرصيد السالب دون تحذير».
- **المدخرات:** بطاقة المحفظة تعرض «للادخار · المتاح» وتفتح أهدافها. مصروف يأخذ من مال مخصص لهدف يُنبَّه عليه، وعند المتابعة يُنقص المخصص تلقائيًا.
- **صافي أموالك:** إن وُجدت ديون، سطر تحت الرصيد الإجمالي: لي عند الناس · علي للناس · صافي أموالك (والمتأخر بلون مميز).
- **الصوت المتواصل** في «اكتب يومك»: يستمع حتى «إيقاف» مهما كانت السكتات، مع عدّاد، ويتوقف وحده بعد 8 ثوانٍ سكوت أو 3 دقائق. لا تحليل قبل أن تضغط «تحليل».
- **وضع الخصوصية:** زر العين بجانب الرصيد يُخفي كل المبالغ («••••• أوقية»)؛ الضغط المطوّل على مبلغ يُظهره وحده لثوانٍ. في الإعدادات: الإخفاء عند فتح التطبيق، وفي Android إخفاء صورة التطبيق في قائمة التطبيقات المفتوحة. التصدير يبقى بالمبالغ الحقيقية.

## التشغيل محليًا

المتطلبات: [Node.js](https://nodejs.org) الإصدار 20 أو أحدث (جُرّب على 24).

```bash
npm install
```

```bash
npm run dev
```

ثم افتح `http://localhost:5173`. لتجربته على هاتفك في نفس شبكة Wi-Fi:

```bash
npm run dev -- --host
```

وافتح العنوان الذي يظهر (`http://192.168.x.x:5173`). ملاحظة: البصمة والتثبيت كتطبيق يحتاجان HTTPS، لذا جرّبهما على النسخة المنشورة.

أوامر أخرى:

| الأمر | الوظيفة |
|---|---|
| `npm test` | تشغيل الاختبارات (الأرصدة، التحويلات، التقسيم، الفترات، التراجع، النسخ الاحتياطي، البحث، الديون، التكرار، العملات، الزكاة، الترحيل…) |
| `npm run build` | فحص الأنواع وبناء النسخة النهائية في `dist/` |
| `npm run preview` | تجربة النسخة النهائية محليًا (مع Service Worker) |
| `npm run icons` | إعادة توليد أيقونات التطبيق |

## التحديثات

عند نشر نسخة جديدة، تُنزَّل في الخلفية عند فتح التطبيق وتنتظر: **تُطبَّق عند إغلاق التطبيق وإعادة فتحه** (أو فورًا من بانر "نسخة جديدة جاهزة"). لا تُعاد الصفحة أثناء الاستعمال، ولا حاجة لحذف التطبيق. تغييرات قاعدة البيانات تتم بترحيل يحافظ على كل البيانات (`src/data/db.ts`، ومختبَر في `src/tests/migration.test.ts` على قاعدة حقيقية من المرحلة الأولى).

## النشر المجاني على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub (مثلًا باسم `jeybi`).
2. ارفع المشروع:
   ```bash
   git remote add origin https://github.com/<اسمك>/jeybi.git
   ```
   ```bash
   git push -u origin main
   ```
3. في المستودع: **Settings ← Pages ← Source** واختر **GitHub Actions**.
4. كل `push` إلى `main` يشغّل الاختبارات ثم يبني وينشر تلقائيًا (الملف `.github/workflows/deploy.yml`). يضبط المسار `BASE_PATH` باسم المستودع تلقائيًا.
5. الرابط يكون: `https://<اسمك>.github.io/jeybi/`

### بديل: Netlify

اربط المستودع بـ Netlify، والإعدادات جاهزة في `netlify.toml` (الأمر `npm run build`، المجلد `dist`).

## تطبيق Android (ملف APK)

نفس التطبيق كتطبيق Android حقيقي (Capacitor): بصمة Android الأصلية، إشعارات تصل والتطبيق مغلق، مشاركة مباشرة إلى واتساب، ونسخ احتياطي تلقائي مشفّر. نسخة الويب أعلاه تبقى تعمل كما هي.

### التحميل والتثبيت (أول مرة)

1. على الهاتف، افتح في Chrome: **https://github.com/yede3333-star/jeybi/releases/latest**
2. اضغط على **jeybi.apk** (تحت Assets) لتحميله. إن ظهر تنبيه "قد يكون هذا الملف ضارًا"، اختر **تنزيل على أي حال**.
3. افتح الملف من إشعار التنزيل (أو من تطبيق **الملفات ← التنزيلات**).
4. أول مرة سيقول Android إن التثبيت من هذا المصدر غير مسموح:
   - اضغط **الإعدادات** في الرسالة، ثم فعّل **السماح من هذا المصدر** (السماح لـ Chrome أو لتطبيق الملفات بتثبيت التطبيقات).
   - ارجع (زر الرجوع) واضغط **تثبيت**.
   - المسار اليدوي إن احتجته: **الإعدادات ← التطبيقات ← الوصول الخاص ← تثبيت التطبيقات غير المعروفة ← Chrome ← مسموح** (يختلف الاسم قليلًا حسب الهاتف).
5. إن ظهر **Play Protect** وقال إن التطبيق غير معروف: اختر **تفاصيل أكثر ← التثبيت على أي حال**. هذا طبيعي لأي تطبيق لا يأتي من متجر Play.
6. افتح **جيبي** من الشاشة الرئيسية.

بعد التثبيت (مرة واحدة):
- **الإعدادات ← إشعارات الهاتف**: فعّلها واسمح بالإشعارات (التذكير اليومي، مواعيد الديون، اكتمال الحول).
- **الإعدادات ← القفل والبصمة**: أنشئ رمزًا ثم فعّل البصمة.
- **الإعدادات ← النسخ الاحتياطي ← نسخ تلقائي أسبوعي**: اختر كلمة مرور. النسخ تُحفظ في `Documents/Jeybi` وتبقى حتى لو حُذف التطبيق.

### التحديث

كل تحديث يظهر كإصدار جديد في نفس الصفحة (**releases/latest**). حمّل **jeybi.apk** الجديد وثبّته **فوق** النسخة الموجودة (لا تحذف التطبيق أولًا): Android يعرضه كـ"تحديث"، وكل البيانات والإعدادات تبقى. رقم النسخة يظهر أسفل صفحة الإعدادات (مثل `v1.0.0 (142)`).

لا تحذف التطبيق قبل التحديث: الحذف يمسح بياناته. إن احتجت لحذفه، احفظ قبلها نسخة احتياطية مشفّرة وأرسلها خارج الهاتف.

### ملاحظات

- بيانات تطبيق Android منفصلة عن بيانات نسخة الويب في Chrome. للانتقال: من نسخة الويب **النسخ الاحتياطي ← إنشاء نسخة**، ثم في التطبيق **استعادة من نسخة**.
- النسخ الاحتياطية الآن **مشفّرة بكلمة مرور** (AES-GCM). إن نُسيت كلمة المرور فلا يمكن استرجاع النسخة. النسخ القديمة غير المشفّرة ما زالت تُستعاد.
- التطبيق لا يرسل أي شيء عبر الإنترنت، ولا يستعمل نسخ Google الاحتياطي (`allowBackup=false`).

### البناء على GitHub (للمطوّر)

كل `push` إلى `main` يشغّل الاختبارات، ثم ينشر نسخة الويب، ويبني **APK موقّعًا** وينشره في Releases (الملف `.github/workflows/deploy.yml`). رقم الإصدار يزيد تلقائيًا (`versionCode` = عدد الـ commits).

التوقيع يحتاج سرّين في **Settings ← Secrets and variables ← Actions** (مرة واحدة):

| الاسم | القيمة |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | محتوى الملف `jeybi-release.p12.base64.txt` |
| `ANDROID_KEYSTORE_PASSWORD` | محتوى الملف `password.txt` |

الملفات في `Documents\Jeybi-signing-key` على حاسوب المطوّر، **خارج** المستودع (المستودع عام). احتفظ بنسخة منها في مكانين آخرين: **ضياع المفتاح يمنع أي تحديث للتطبيق مستقبلًا**. دون السرّين يُبنى APK غير موقّع للتحقق فقط، ولا يُنشر إصدار.

لتجربة البناء محليًا (اختياري، يحتاج JDK 21 و Android SDK): `npm run build`، ثم `npx cap sync android`، ثم `cd android` و `./gradlew assembleDebug`.

## تثبيت نسخة الويب على هاتف Android (بدون APK)

1. افتح رابط التطبيق في **Chrome** على الهاتف.
2. انتظر حتى يكتمل التحميل (مرة واحدة فقط — بعدها يعمل بدون إنترنت).
3. اضغط على قائمة **⋮** أعلى المتصفح ← **إضافة إلى الشاشة الرئيسية** / **تثبيت التطبيق**.
4. ستظهر أيقونة **جيبي** على الشاشة الرئيسية، ويفتح كتطبيق مستقل بدون شريط المتصفح.

نصائح مهمة:
- البيانات محفوظة في هذا المتصفح على هذا الهاتف فقط. **لا تمسح بيانات Chrome** للموقع، واحفظ **نسخة احتياطية** بانتظام (الإعدادات ← النسخ الاحتياطي) وأرسلها لنفسك على واتساب.
- لتفعيل البصمة: الإعدادات ← القفل والبصمة ← أنشئ رمز PIN ثم فعّل البصمة.
- عند نشر تحديث جديد، يتحدّث التطبيق تلقائيًا عند فتحه التالي مع اتصال بالإنترنت.

## البنية التقنية

React + TypeScript + Vite، و Tailwind CSS v4 (مع RTL)، و Dexie (IndexedDB)، و `vite-plugin-pwa`، و `react-i18next`، و Recharts، و SheetJS، و `html-to-image` + `jsPDF`.

```
src/
  data/       نموذج البيانات وقاعدة Dexie والقيم الافتراضية
  repo/       كل الوصول للبيانات (المحافظ، التصنيفات، العمليات، القوالب، الديون، الميزانيات، المتكررة، الأهداف، الزكاة، النسخ الاحتياطي…)
  services/   حسابات صافية (التقارير، الأرصدة، الفلترة) + الأمان + التصدير
  lib/        المال (×100) والتنسيق والفترات
  hooks/      ربط React بالبيانات والإعدادات
  platform/   طبقة المنصة: الويب أو Android (Capacitor) — البصمة، الإشعارات، المشاركة، الملفات
  components/ مكونات الواجهة (نافذة الإدخال، القفل، الرسوم…)
  pages/      الشاشات
  i18n/       العربية والفرنسية
  tests/      الاختبارات
```

- المبالغ مخزّنة كأعداد صحيحة (×100) لتجنّب أخطاء الكسور.
- الواجهة لا تصل لقاعدة البيانات إلا عبر `src/repo/`، ولا إلى إضافات Android إلا عبر `src/platform/` (تُحمَّل داخل التطبيق فقط؛ نسخة الويب لا تنزّلها).
- مشروع Android في `android/`، وإعداده في `capacitor.config.ts`. **لا تغيّر** `appId` ولا `server.hostname`/`androidScheme`: قاعدة البيانات مرتبطة بهما، وتغييرهما يُظهر التطبيق فارغًا بعد التحديث.
- مخطط قاعدة البيانات مرقّم: `version(1)` للمرحلة الأولى و`version(2)` للثانية (جداول جديدة فقط، دون تعديل البيانات القائمة). أي تغيير لاحق = `version(3)`.
